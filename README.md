# RandomFood

RandomFood là website giúp người dùng khám phá và lựa chọn món ăn phù hợp cho mỗi bữa ăn. Ứng dụng hỗ trợ tìm kiếm, lọc món theo danh mục và vùng miền, cũng như chọn món ngẫu nhiên.

Website được xây dựng bằng PHP theo mô hình MVC, sử dụng MySQL để lưu trữ dữ liệu và có giao diện responsive. Các luồng chính gồm Guest Flow, User Flow và Admin Flow, với những chức năng như quản lý món yêu thích, lịch sử lựa chọn, hồ sơ người dùng và đánh giá món ăn.
